# Sitar Test Reports

This directory is generated by `test/run_tests.py`.

Each run is stored as:

```
reports/
  run_YYYYmmdd_HHMMSS/
    build.log
    config.json
    results.csv
    results.json
    summary.md
    plots/
      cycles.png
      ipc.png
      hit_rates.png
      bus_mix.png
      coherence.png
      wb_latency.png
      stalls.png
      atomic_share.png
    raw/
      balanced.log
      read_only.log
      ...
  latest -> run_YYYYmmdd_HHMMSS
```

Start with `latest/summary.md` for the pass/fail table and links to plots.
Use `latest/results.csv` for spreadsheets and `latest/results.json` for full
machine-readable validation and metric detail.

The suite validates both performance and coherence correctness:

- completion of 1000 instructions on both cores
- IFETCH data and atomic old-value data checks
- cache request partitions, bus atomic accounting, and writeback accounting
- absence of simulator errors and invariant violations
- static check that icaches are not snooped or invalidated
- `BOTH-DIRTY` events are surfaced as warnings, not hidden

Do not edit generated run directories by hand. Re-run the suite instead.
